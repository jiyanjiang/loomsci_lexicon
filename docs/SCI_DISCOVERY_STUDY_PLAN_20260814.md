## 一、问题定义的形式化

### 1.1 科学发现的操作性定义

本方案的核心贡献在于：**不依赖人工标注或领域专家判断，而是从概念共现网络的时间序列中严格地、可复现地定义"科学发现"**。

设概念对 (A, B) 在年份 t 的共现频次为 N(AB, t)，其中 t ∈ {2008, ..., 2025}。定义：

**定义 1（弱发现）**：概念对 (A, B) 构成一次科学发现，当且仅当存在年份 YYYY ∈ (2008, 2025]，使得：

1. ∀ t < YYYY：N(AB, t) < N_c（突破前从未稳定达到阈值）
2. ∀ t ≥ YYYY：N(AB, t) ≥ N_c（突破后持续保持）

**定义 2（强发现）**：在弱发现基础上，额外要求增长斜率条件：

3. 存在连续两年 t₁, t₂ ∈ [YYYY, YYYY+2]，使得 [N(AB, t₂) − N(AB, t₁)] / N(AB, t₁) > k_c

其中 N_c 为共现阈值（默认 N_c = 10），k_c 为增长率阈值（默认 k_c = 0.5，即年增长 50%）。

**定义 3（发现三元组）**：每个满足上述定义的概念对对应一个发现三元组：

$$\mathcal{D} = (N_c, k_c, YYYY)$$

其中 YYYY 称为**突破年（breakthrough year）**。

这一形式化的关键优势在于：

- **可复现性**：给定 N_c 和 k_c，任何研究者可独立从数据中推导出相同的发现集合与突破年
- **可审计性**：发现年不依赖"该领域何时变热"的主观判断
- **可扩展性**：N_c 和 k_c 作为自由参数，可进行敏感性分析

### 1.2 核心研究问题

**主问题**：G(AB, t) 的时间行为能否在统计意义上预言 YYYY？

**子问题**：

- Q1：在突破年 YYYY，归一化电导 G_norm(AB, YYYY) 是否呈现稳定的分布特征（集中趋势、分位数）？
- Q2：G_norm(AB, t) 的上升是否系统性地**早于** N(AB, t) 的突破（间接路径先行假说）？
- Q3：G_norm(AB, t) 的 S 曲线拐点与 YYYY 之间是否存在可检验的对应关系？
- Q4：上述规律对 N_c 的取值是否敏感？在不同领域（astro / quantum / AI）间是否稳健？

### 1.3 间接路径机理的形式化

本方案区别于朴素共现统计的核心在于对**间接路径**的严格处理。设概念网络在年份 t 的邻接矩阵为 W(t)，其中 W_ij(t) = N(i, j, t)（共现频次）。定义图拉普拉斯 L(t) = D(t) − W(t)，其中 D 为度矩阵。有效电导 G(AB, t) 定义为：

$$G(AB, t) = \frac{1}{L^\dagger_{AA}(t) + L^\dagger_{BB}(t) - 2L^\dagger_{AB}(t)}$$

其中 L† 为 L 的 Moore-Penrose 伪逆。

**关键性质**：当 A 与 B 在年份 t 无直接共现（W_AB(t) = 0）时，G(AB, t) 仍可非零。这是因为 L† 编码了图中所有路径的信息。具体地，对于路径 A→C→B（共同邻居 C）：

$$L^\dagger_{AB} \propto \sum_C \frac{W_{AC} W_{CB}}{d_C} + \sum_{C,D} \frac{W_{AC} W_{CD} W_{DB}}{d_C d_D} + \cdots$$

因此，**G(AB, t) 度量的是"潜在连接强度"**——即使 A、B 从未直接共现，通过中间概念的网络结构，它们之间仍存在非零电导。

**预言性假说的数学表述**：

$$\text{若 } G(AB, t) \text{ 在 } t < YYYY \text{ 时持续上升，则 } N(AB, t) \text{ 将在 } YYYY \text{ 突破 } N_c$$

这一假说的机理是：科学发现不是孤立事件，而是概念生态系统中知识重组的前兆。当两个概念通过间接路径（共同邻居、更长的概念链）在网络中逐渐靠近时，直接共现的爆发往往随之而来。**G 捕捉的是"知识融合的潜势"，而 N 记录的是"知识融合的实现"**。

## 三、分阶段实施计划

### 阶段 0：发现集构建（第 1-2 周）

**目标**：从数据中严格推导发现三元组集合。

**步骤**：

1. 对 1974 个概念对，计算 N(AB, t) 序列（t = 2008-2025）
2. 对每个概念对，扫描所有可能的 YYYY ∈ (2008, 2025]，检验弱发现条件
3. 对满足弱发现的对，进一步检验强发现条件（k_c = 0.5）
4. 记录每个发现的 (N_c, k_c, YYYY) 三元组
5. 输出：发现集 D(N_c=10, k_c=0.5) = {(A_i, B_i, YYYY_i)}，预期 30-50 个案例

**质量控制**：

- 排除 YYYY ≤ 2009 的案例（观察窗口太短，无法确认"突破前"状态）
- 排除 YYYY ≥ 2023 的案例（突破后观察期不足 3 年）
- 对每个案例，人工抽查 N(AB, t) 序列，确认突破的视觉合理性

### 阶段 1：作图——直觉证据（第 2-4 周）

**目标**：为每个发现案例生成 G(AB, t) 与 N(AB, t) 的对照时间序列图。

**图表设计**：

- 双 Y 轴图：左轴 N(AB, t)（柱状图），右轴 G_norm(AB, t)（折线图）
- 垂直虚线标注 YYYY 位置
- 对 G_norm 曲线进行 LOESS 平滑（span = 0.4），叠加原始值散点
- 标注 G_norm 在 YYYY 年的值 G_norm_c

**预期产出**：30-50 张案例图，按领域分组（astro / quantum / AI / 其他）。

**直觉检验**：目视检查 G_norm 是否在 YYYY 之前或附近出现上升趋势。记录以下模式：

- **模式 P1（预言型）**：G_norm 在 YYYY 前 1-3 年开始上升，YYYY 时达到局部高点
- **模式 P2（同步型）**：G_norm 与 N 同时上升
- **模式 P3（滞后型）**：G_norm 在 YYYY 后才上升
- **模式 P4（无规律型）**：G_norm 无明显趋势

### 阶段 2：统计检验——G_norm_c 的分布规律（第 4-6 周）

**目标**：检验 G_norm_c = G_norm(AB, YYYY) 是否呈现稳定的统计规律。

**分析内容**：

1. **集中趋势**：计算 G_norm_c 的均值、中位数、标准差，检验变异系数 CV = σ/μ 是否足够小（如 CV < 0.5 视为"集中"）

2. **分位数稳定性**：对 G_norm_c 进行 bootstrap 重采样（n = 10000），计算 95% 置信区间。若区间宽度 < 均值的 30%，认为存在"固定 G_norm_c"

3. **跨领域比较**：按领域分组，检验各领域 G_norm_c 分布是否一致（Kruskal-Wallis 检验）

4. **与随机基准比较**：生成随机 YYYY 序列（保持 YYYY 的年份分布不变，但随机分配给不同概念对），计算对应的 G_norm 值分布。用 KS 检验比较真实 G_norm_c 分布与随机分布。**若真实分布显著更集中（p < 0.05），则 G 具有预言信息**

5. **S 曲线拐点检验**（详见阶段 3）

### 阶段 3：S 曲线拐点检验（第 6-8 周）

**目标**：检验 G_norm(AB, t) 的 S 曲线拐点与 YYYY 的对应关系。

**方法**：

1. **S 曲线拟合**：对每个案例的 G_norm(AB, t) 序列（t = 2008-2025），拟合 Logistic 函数：

$$G(t) = \frac{G_{max}}{1 + e^{-r(t - t_0)}} + G_{min}$$

其中 t₀ 为拐点（斜率最大处），r 为增长率参数。

2. **拐点提取**：对拟合质量良好的案例（R² > 0.6），提取 t₀

3. **对应关系检验**：计算 Δ = t₀ − YYYY（拐点相对突破年的偏移）。检验：

   - **H1（预言假说）**：Δ 的中位数显著小于 0（G 拐点早于突破年），且 |Δ| 的分布集中
   - **H0（零假说）**：Δ 的中位数不显著偏离 0
   - 使用 Wilcoxon 符号秩检验（α = 0.05）

4. **间接路径先行的直接检验**：对于每个案例，计算"间接路径强度"指标：

$$I(AB, t) = \sum_{C \neq A,B} \min(N(AC, t), N(CB, t))$$

检验 I(AB, t) 的上升是否早于 N(AB, t) 的突破。若 I 的拐点系统性早于 N 的突破，则间接路径先行假说得到直接支持。

### 阶段 4：N_c 敏感性分析（第 8-10 周）

**目标**：检验发现定义和 G_norm_c 规律对 N_c 取值的稳健性。

**方法**：

1. **N_c 扫描**：对 N_c ∈ {5, 8, 10, 15, 20, 30}，重复阶段 0-2 的分析
2. **发现集稳定性**：计算不同 N_c 下发现集的重叠率（Jaccard 指数）。若 N_c = 10 与 N_c = 15 的发现集重叠 > 70%，认为发现定义稳健
3. **G_norm_c 规律稳定性**：对每个 N_c 取值，计算 G_norm_c 的集中度指标（CV、bootstrap 区间宽度）。若规律在多个 N_c 下保持一致，则结论稳健
4. **跨领域 N_c 差异**：分别对 astro / quantum / AI 子集重复分析，检验是否存在领域特定的最优 N_c

**输出**：N_c 敏感性热力图 + 跨领域稳健性报告。

### 阶段 5：综合判定与报告（第 10-12 周）

整合所有分析结果，形成最终判定（见下一节）。

## 四、判定标准

### 4.1 "G 能预言科学发现"的判定标准

以下条件**同时满足**时，判定 G 具有预言能力：

**C1（分布集中性）**：G_norm_c 的变异系数 CV < 0.5，且 bootstrap 95% CI 宽度 < 均值的 30%

**C2（与随机基准的区分）**：KS 检验显示真实 G_norm_c 分布显著不同于随机 YYYY 对应的 G_norm 分布（p < 0.05），且真实分布的方差显著更小（Levene 检验 p < 0.05）

**C3（拐点先行）**：S 曲线拐点偏移 Δ = t₀ − YYYY 的中位数 < 0，且 Wilcoxon 检验 p < 0.05

**C4（N_c 稳健性）**：在至少 3 个不同的 N_c 取值下（如 8, 10, 15），C1-C3 的定性结论保持一致

**C5（跨领域一致性）**：至少在 2 个领域（如 astro 和 quantum）中，G_norm_c 的集中趋势方向一致（中位数差异 < 1 个标准差）

### 4.2 部分支持的情形

- **强预言（G 先行）**：C1-C5 全部满足，且 Δ 中位数 < −1 年
- **弱预言（G 同步/略先行）**：C1-C4 满足，但 Δ 中位数在 [−1, 0] 年之间
- **条件预言（领域特定）**：仅在部分领域满足 C1-C3

### 4.3 否定标准

以下任一情况出现，则判定 G **不具有**可靠的预言能力：

**N1**：G_norm_c 的 CV > 1.0（分布高度分散，无集中趋势）

**N2**：真实 G_norm_c 分布与随机基准无显著差异（KS 检验 p > 0.3）

**N3**：Δ 中位数 > +1 年（G 拐点系统性晚于突破年）

**N4**：规律在 N_c 敏感性分析中完全消失（仅在一个 N_c 取值下成立）

## 五、风险与失败路径

### 5.1 风险识别

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 发现集过小（< 20 个） | 中 | 统计功效不足 | 放宽 N_c 至 5，或扩展至弱发现定义 |
| G_norm_c 无集中趋势 | 中高 | 核心假说受挑战 | 转向"变化率"分析：检验 ΔG_norm 而非 G_norm_c 本身 |
| S 曲线拟合失败 | 中 | 拐点检验无法进行 | 使用非参数拐点检测（如 Pettitt 检验） |
| 领域间异质性过大 | 中 | 无法得出统一结论 | 分领域报告，寻找领域特定的规律 |
| AI 领域数据质量差（D4 TRUE 率仅 30%） | 高 | AI 子集结论不可靠 | 将 AI 作为敏感性分析而非核心证据 |

### 5.2 失败路径的诚实处理

**如果 G_norm_c 无规律（N1 或 N2 成立）**，这本身是一个重要的科学发现。可能的解释与后续方向：

**解释 1：G 度量的是"潜势"而非"实现"**。并非所有高电导的概念对最终都会直接共现。G 上升是必要条件而非充分条件。后续可研究：什么条件下高 G 能转化为直接共现？（引入"催化因素"分析，如外部事件、技术突破）

**解释 2：归一化方式不当**。标准池锚定可能引入了与发现无关的波动。后续可尝试：按领域内池归一化、按时间窗口滚动归一化、或使用秩归一化（百分位排名）

**解释 3：发现定义过于严格**。N_c = 10 可能过高，排除了许多真实的但规模较小的发现。后续可检验：降低 N_c 至 3-5，或使用相对阈值（如 N 相对于概念对总频次的占比）

**解释 4：G 的时间分辨率不足**。年度聚合可能掩盖了突破的精确时序。后续可尝试：月度或季度级别的 G 序列

**解释 5：间接路径的机理假设有误**。也许 AC/CB 路径的存在并不总是预示 AB 的直接融合。某些概念对通过共同邻居连接但永远不会直接共现（如竞争性概念）。后续可研究：区分"互补型"与"竞争型"间接连接

### 5.3 从失败中提炼边界

无论结果如何，本研究将产出以下**方法论贡献**：

1. **发现的形式化定义**：即使 G 预言失败，发现三元组 (N_c, k_c, YYYY) 的定义本身是可复用的
2. **G_norm_c 的经验分布**：无论是否有规律，这是首个关于"突破年电导水平"的系统性测量
3. **间接路径先行假说的检验框架**：S 曲线拐点偏移检验可应用于其他网络指标
4. **N_c 敏感性的系统分析**：为后续研究提供参数选择的经验依据

## 六、方法学呼应：S 曲线与科学发现的动力学

### 6.1 理论框架

科学发现的经典动力学模型是 **S 形增长**（logistic growth）：一个新概念或概念对在初期缓慢积累，经历拐点后加速增长，最终趋于饱和。这一模式在引文分析、技术采纳、知识扩散等领域被反复验证。

本方案的核心理论创新在于区分了两个层次的 S 曲线：

- **N 层（实现层）**：N(AB, t) 的 S 曲线，代表直接共现的爆发
- **G 层（潜势层）**：G(AB, t) 的 S 曲线，代表间接连接的积累

**核心假说**：G 层的 S 曲线拐点**系统性早于** N 层的 S 曲线拐点。这是因为间接路径（AC/CB、AC/CD/DB）的建立先于直接共现——两个概念首先通过中间概念"认识"彼此，然后才"直接对话"。

### 6.2 可检验推论

**推论 1（时序先行）**：t₀(G) < t₀(N) < YYYY，其中 t₀(·) 为各层 S 曲线拐点

**推论 2（幅度关系）**：G_norm_c 的分布比 N(AB, YYYY)/N_max 的分布更集中（G 的突破水平比 N 的突破水平更稳定）

**推论 3（路径长度演化）**：在突破前，A 与 B 之间的最短路径长度从 > 2 逐渐缩短至 2，最后至 1（直接共现）。这一演化可通过逐年计算最短路径长度来验证

### 6.3 与既有文献的对话

本方案与以下研究脉络对话：

- **科学发现的可预测性**（Clauset et al., 2017; Fortunato et al., 2018）：从网络结构预测新兴研究领域
- **知识重组理论**（Fleming, 2001; Uzzi et al., 2013）：创新源于已有知识元素的新组合
- **链路预测**（Liben-Nowell & Kleinberg, 2007）：基于网络拓扑预测未来连接
- **技术预见**（Porter et al., 2020）：S 曲线在技术成熟度评估中的应用

本方案的独特贡献在于：将"发现"从人工标注中解放出来，用网络动力学指标（G）的统计规律来检验预言性，并严格处理了间接路径的机理。
